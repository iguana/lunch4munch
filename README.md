# Lunch4Munch 🍱

High-protein, no-heat school lunch ideas for a 6th grader, themed on Undertale, Smiling Friends, and Rick and Morty.

Live page: https://iguana.github.io/lunch4munch/

- 48 cold-packable lunches with macros, filters, and packing steps
- Lunchbox Lab: build a lunch from parts, with live macro math and a protein aggression dial
- Week planner with a combined shopping list and a Sunday prep checklist

Nutrition numbers are estimates from typical grocery labels. This is a fan-made family project and isn't affiliated with the shows or game.
